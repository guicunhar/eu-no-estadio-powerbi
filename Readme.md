# Eu no Estádio

Dashboard em Power BI com todos os jogos do Fluminense que eu vi ao vivo, da arquibancada.

Eu mesmo anoto cada jogo: resultado, estádio, público, escalação e gols. O painel transforma essa base no meu diário de torcedor: onde mais fui, quais jogadores mais vi em campo, os maiores públicos, os mata-matas e muito mais, com filtros para montar qualquer consulta.

Projeto 100% pessoal.
